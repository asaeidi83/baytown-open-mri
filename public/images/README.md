# Image assets

Place the following two images in this folder using these exact filenames:

- `open-mri-room.png` — interior photograph of the Open MRI scanner room (used in the homepage hero)
- `clinic-exterior.png` — exterior photograph of the building (used in the homepage location section)

PNG, JPG, or WebP are all fine — just keep the filename root the same.
If you save as JPG/WebP, update the references in:
  - `src/components/sections/hero.tsx`
  - `src/components/sections/location.tsx`
